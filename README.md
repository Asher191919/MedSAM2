# MedSAM2 + 交互式肿瘤分割模仿学习

把**医生的交互式标注过程**视为专家轨迹，训练模型模仿医生下一步如何修正肿瘤边界：

- **状态 s** = 当前图像、当前分割结果、历史点击
- **动作 a** = 下一次点击（正点击 / 负点击=擦除）、框选、或确认
- **目标** = 用尽可能少的交互得到高 Dice 分割

评估不止 Dice：达到目标 Dice 的**点击次数**、每次交互的 **Dice 提升**、不同**肿瘤大小**下的
稳定性、**医生 vs 模型**的交互策略差异。


| 策略 | Dice@1 | Dice@3 | ATTC(≤0.85) | 成功率 | 停手 Dice |
|---|---|---|---|---|---|
| 仅一次点击 | 0.832 | 0.832 | 4.62 | 63.7% | 0.833 |
| 随机修正 | 0.760 | 0.857 | 3.52 | 84.2% | 0.891 |

解读: BC 在 ~4.8k 样本、从头训练 CNN 的条件下达到了医生单击 Dice 的 88%,

8px 动作粒度与样本量 —— 换真 MedSAM2 图像特征 + 真实标注轨迹后应显著缩小。
BC 的失败案例集中在小肿瘤 (small 组 Dice@3=0.674), 见 plot_size_stability.png。

## 真实医生轨迹、ISIC 数据集与点击定位预训练

**① 真实医生标注轨迹**（`scripts/annotate_record.py`）：规则模拟医生终究是规则，
真实医生轨迹需要人来标注。项目内置录制工具：

```bash
python scripts/annotate_record.py --data_dir data/kvasir_seg --out data/real_trajectories.jsonl
# 左键=正点击, 右键=擦除, b=框选, Enter=确认, u=撤销; 每张图一个 JSONL 回合
```

录好后把 `config` 的 `data.real_trajectories` 指向该文件——`run_all` 自动用真实轨迹
回放替代模拟医生的 r0（真实点击直接成为训练标签，初始框按协议视为人类提示）。

**② ISIC 2018 大规模数据集**（1300 对图像/边界 mask，Kvasir 的 1.3 倍、病灶更大更难）：

```bash
python scripts/prepare_real_data.py --dataset isic2018 --shards 25   # 经 hf-mirror
python scripts/run_all.py --config configs/config_isic.yaml          # 完整管线
```

**跨数据集结果**（ISIC 2018, 250 张测试图, 目标 Dice≥0.85; 灰度代 Kvasir 最终版
BC = 81.0% [95% CI 73–88%] / ATTC 3.20, 最新彩色版见下文）:

| 策略 | Dice@1 | Dice@3 | ATTC | 成功率 |
|---|---|---|---|---|
| 仅单次交互（只框不修） | 0.858 | 0.858 | 3.92 | 70.8% |
| 随机修正 | 0.858 | 0.887 | **2.01** | **97.6%** |
| 模拟医生（规则专家） | 0.858 | 0.879 | 2.50 | 89.2% |
| **模仿学习策略 (BC)** | 0.858 | 0.859 | **3.12** | **80.4%** |

ISIC 上 BC 领先单次交互基线 **+9.6pp**（250 图测试集, σ≈2.5pp, 显著）;
医生平均只需 2.44 次交互（皮肤病灶边界清晰, 框提示很有效）。
两个数据集汇总: Kvasir 78.0%/3.44, ISIC 80.4%/3.12 —— 管线跨模态稳定
(内镜/皮肤镜), 模拟医生仍是上界, BC 的差距随数据量与预训练持续收窄。

**③ 点击定位专项预训练**（不需要轨迹，从 GT 直接合成监督）：对每张图模拟退化的
当前 mask（框/腐蚀/膨胀/错位），按医生规则合成"应点位置"的热图目标监督
trunk+点击头；完美 mask 教 stop 头"该停"。配置 `policy.click_pretrain_epochs`。

**④ 多假设分歧 + 辅助误差头 + RL 微调**（最新一代）:
- SAM2 每次提示返回 3 个候选 mask，**候选间分歧图**与分数方差作为状态的
  第 10/11 通道（不依赖 GT 的不确定性信号）；
- **辅助误差头**：训练时预测 GT 的 FN/FP 误差图，迫使特征学会
  "从图像-分割不一致中找误差"；
- **验证集任务成功率选轮**（val 上直接跑 BC 回合测成功率，不碰测试集）；
- **RL 微调**（REINFORCE，奖励 = 每次交互的 ΔDice + 达标停手 ±0.5）：
  小预算下（300 回合 × 2 轮）未超过 BC（79.3% → 76.3% → 77.0%），
  验证集护栏自动保留了 BC——诚实的负结果，扩大 RL 预算是明确方向。

Kvasir 最终消融（100 张测试图, bootstrap 95% CI; 种子间波动 ±3pp）:

| 变体 | 成功率 [CI] | ATTC |
|---|---|---|
| 基线（500 图） | 69.0% [58, 76] | 4.15 |
| +900 图 + 自信度 + F0.5 + DAgger | 78.0% | 3.52 |
| + 嵌入分支 | 71.0% | 3.95 |
| + 点击预训练 | 78.0% | 3.44 |
| **+ 多假设分歧 + 误差头（灰度出货）** | **81.0% [73, 88]** | **3.20** |
| + RL 微调（小预算） | 79.3% (val)，测试不采用 | — |

> 以上为灰度代消融。当前出货已升级为彩色全栈 + 高分辨率误差/偏移头 +
> 测试时候选搜索（Kvasir 87.0% / ATTC 2.34），完整对比见下文
> "真实数据结果"与"三项性价比改进"两节。

被实验否决并保留代码开关的方案（负结果也是结果）:
- **Dice 回归停手**（预测 Dice >= 阈值）：两次尝试（L1 与 BCEWithLogits 软标签）
  均劣于 F0.5 校准的分类器停手（67–79% vs 82%），已回退
  （`policy.stop_mode: classifier`，回归头代码保留可切换）；
- **辅助 Dice 回归损失**（dice_loss_weight>0）：无增益（79 vs 82），默认关闭；
- **一次交互双修正**（`policy.dual_mode: true`，每步同时输出一正一负点击）：
  机制完整实现并评测，76.0%/ATTC 3.63 **劣于**单动作 81.0%/3.20 ——
  7k 样本不足以让网络每步可靠地放置两个点击（次通道误触发损伤好 mask）；
  医生侧双修正有效（89–92% 不变）。基础设施保留，更大数据量下值得重试；
- **停手护栏**（连续自信度无提升即停）：误停严重，已关闭。

```bash

```

流程：Kvasir-SEG 息肉 1000 张（900 张轨迹 / 100 张评测）→ 真 MedSAM2 后端
（官方 wanglab/MedSAM2 权重）→ **两阶段模仿学习**：纯专家轨迹训 BC v1 →
**DAgger 在线聚合**（BC 与医生混合执行回合、医生在 BC 走到的每个状态上打标签，

**真实协议**：初始框选是"人类用户"给的提示（所有策略共享同一个抖动 GT 框，
模拟医生先框住目标的内镜标注工作流），模型学习的是**下一步如何修正肿瘤边界**
（点击/擦除/确认）。状态含 13 通道（RGB 图像 3 通道 + 分割/历史/不确定性 10 通道），
其中"分割器自信度"（MedSAM2 predicted-IoU）
是停手决策的关键输入。合成数据管线保持"策略自己点第一下"的协议（config.yaml）。

### 真实数据结果（Kvasir-SEG × 真 MedSAM2, 100 张测试图, 目标 Dice≥0.85）

当前出货版本 = 彩色全栈（MedSAM2 后端与策略 13 通道状态均吃 RGB）+ 高分辨率
误差头 + 亚格子偏移头（见下文"三项性价比改进"）:

| 策略 | Dice@1 | Dice@3 | ATTC | 成功率 |
|---|---|---|---|---|
| 仅单次交互（只框不修） | 0.900 | 0.900 | 2.70 | 83.0% |
| 随机修正 | 0.900 | 0.905 | **1.97** | **92.0%** |
| 模拟医生（规则专家） | 0.900 | 0.908 | **1.97** | **92.0%** |
| **模仿学习策略 (BC)** | 0.900 | 0.900 | 2.34 | **87.0%** |

注: Dice@1 从灰度版的 0.858 升到 0.900 **不是策略的功劳**——是 MedSAM2 后端
改吃 RGB 原图（此前整条管线转灰度再复制成 3 通道, 白白丢掉内镜颜色）, 框提示
Dice 随之上涨, "成功"（≥0.85）的含金量也变了。因此与旧表的绝对数字不可直接
横比; 同一后端内比较: BC 领先单次交互 +4.0pp, 与规则医生的差距从灰度版的
10pp 收窄到 5pp。

### 三项性价比改进（按性价比排序实施, 2026-10）

1. **测试时候选搜索**（纯部署技巧, 不重训、不碰 GT）: 策略每步提出 top-k 个
   候选点击（切比雪夫距离 ≥2 格去重）, 逐个喂给分割器试点, 用 MedSAM2 自己的
   predicted-IoU 选最好的执行, 试完即回滚（`eval.candidates`）。
   旧灰度策略上的消融（k=1 与出货基线逐位一致, 归因干净）:
   k=1: 81.0%/ATTC 3.20 → k=2: 81.0%/3.21 → k=3: **83.0%/3.05**。
   **新彩色策略上无增益**: k=1/2/3 均为 87.0%（仅 Dice@3 +0.2pp, ATTC 持平）,
   因此出货配置保持 `eval.candidates: 1`。
   解读: 候选搜索的价值取决于策略自身的选点质量——灰度策略的第一选择较弱,
   重排序有 +2pp 空间; 彩色策略的首选点击已被分割器背书, 热图次峰里没有
   剩余价值。机制保留（`scripts/sweep_new_candidates.py` 可随时复测）,
   策略退步或换弱后端时它是免费保险。成本: 每步多 1-2 次轻量解码（~0.1s 级）。
2. **皮肤镜/内镜 RGB 输入**: 状态通道 11→13（图像 3 通道 + 原有历史/不确定性
   通道）, MedSAM2 后端同步吃 RGB 原图（`data.color`）。全管线重跑:
   BC 成功率 81.0%→**87.0%**, ATTC 3.20→**2.34**。注意其中约 4pp 来自后端
   改吃 RGB 后框提示 Dice 水涨船高（0.858→0.900）, 属于整条管线的增益。
3. **高分辨率误差头 + 亚格子偏移头**: 误差头从 16×16 搬到 32×32（图像 1/4
   分辨率）特征上预测误差图, 小病灶定位不再天然糊; 新增偏移头在点击定位
   预训练中监督格内亚像素偏移（tanh×0.5 格）, 推理由适配器换算成像素,
   点击精度 8px→约 4px（`policy.fine_offset`）。与 2 同一次重跑合并验证。

顺带修掉的隐性 Bug: **DAgger 混合执行时 BC 点击坐标系错误**——网格下标被
当作像素执行, BC 的点击全部落在图像左上角 16×16 像素内（DAgger 收集的"BC
状态分布"实际是坏分布）。修复后 DAgger 回合最终 Dice 0.787→0.893, 但按验证
集成功率选轮仍选 round0（87.4% vs 85.2%）——DAgger 的收益仍未兑现, 继续作为
负结果记录（见下）。

### BC 的改进轨迹与消融（同一 100 张测试图, σ≈4pp 噪声带内需谨慎解读）

| 变体 | 成功率 | ATTC | 备注 |
|---|---|---|---|
| 专家轨迹 500 图 + 单轮 DAgger | 69.0% | 4.15 | - |
| +900 图 + 自信度通道 + F0.5 + DAgger r1 | 78.0% | 3.52 | - |
| + 嵌入分支 + 点击预训练 + 分歧/误差头（灰度出货版） | 81.0% | 3.20 | val_heat 选轮 |
| + 测试时候选搜索 k=3（灰度版, 不重训） | 83.0% | 3.05 | 部署时技巧 |
| + RGB 全栈 + 高分辨误差/偏移头 + DAgger Bug 修复 | **87.0%** | **2.34** | val 成功率选轮, round0 |
| + 测试时候选搜索 k=2/3（彩色版, 不重训） | 87.0% | 2.34/2.35 | 无增益, 默认关闭 |

诚实的结论:
- **彩色是本代最大单项增益**（81→87）, 且同时抬高了后端（框提示）与策略两端;
  候选搜索在灰度策略上 +2pp（σ≈4pp 噪声带边缘）, 在彩色策略上无增益——
  零成本技巧的收益随策略变强而消失, 已记录为条件性正/负结果。
- **停手护栏被实验否决**: 用 MedSAM2 predicted-IoU 做"连续 2 次无提升即停"反而
  降成功率（误停）, 已默认关闭（`eval.stop_guard: false`）。
- **DAgger 第二轮仍无增益**: 即使修好坐标 Bug、回合质量显著变好（0.893）,
  round1 仍以 2.2pp 输给 round0——瓶颈仍在点击定位的表征质量, 而非数据轮次。
- 下一步真正的杠杆: 用真实医生的标注轨迹替换规则模拟医生（消除示范噪声）与
  更大数据量（ISIC 全量）。（"医生每次采样多候选抬高蒸馏上限"已在 ISIC 上
  实验否决, 见下文⑦: 教师更强 ≠ 学生更强。）

### 评估严谨性与上界调查（④⑤⑦）

**④ 零样本跨数据集迁移**（Kvasir 训练的彩色策略直接上 ISIC 2018 测试集,
250 张, 不做任何微调; `configs/config_isic_rgb.yaml` + `scripts/eval_flexible.py`）:

| 策略 | Dice@1 | Dice@3 | ATTC | 成功率 |
|---|---|---|---|---|
| 仅单次交互（同回合配对基线） | 0.858 | 0.858 | 3.92 | 70.8% |
| 模拟医生 | 0.858 | 0.880 | 2.54 | 90.4% |
| 随机修正 | 0.858 | 0.886 | **2.04** | **97.6%** |
| **BC（Kvasir 零样本）** | 0.858 | 0.822 | 3.69 | **74.0%** |

域差是真实的: **87.0%（Kvasir 域内）→ 74.0%（ISIC 域外, -13pp）**; 更值得注意的是
Dice@3 = 0.822 **低于** 框提示的 0.858 —— 策略在域外前几步的修正是负作用,
靠后续交互才爬回 74%。交互分割文献很少报告跨数据集迁移, 这里给出量化定价。

**⑤ 配对统计检验**（同一批 100 张、同一初始抖动框; McNemar 精确检验;
`scripts/eval_stats.py`, 明细 `outputs/stats_kvasir_rgb.md`）:
- **BC vs 仅单次交互: 不一致对 4-0（@0.85）/ 6-0（@0.90）—— BC 从未让任何一张
  图变差**; p=0.125 / p=0.031, 目标越难越显著。ATTC 敏感性（@0.80/0.85/0.90）:
  1.61 / 2.34 / 3.98（基线 1.70 / 2.70 / 4.50）。
- 模拟医生 vs 仅单次: +9pp @0.85, 9-0, p=0.004（显著 —— 规则教师的修正能力是真的）。
- BC vs 模拟医生: @0.85 医生领先 5pp（0-5, p=0.063）; @0.90 反超 +3pp（6-3, p=0.51）
  —— 教师只在"达标即停"的低目标区间占优。

**⑥ 通道消融**（评测时逐通道置零, 出货策略对 13 通道状态的依赖;
`scripts/ablate_channels.py`, 明细 `outputs/ablation_channels.md`）:
基线 87.0% / ATTC 2.34。**没有任何单通道承重**（全部 Δ 在 ±2pp 噪声带内）,
方向上真正被策略使用的是两个: **当前分割概率图**（置零 -2.0pp, ATTC +0.18）
与**候选 mask 分歧图**（-1.0pp, +0.12）——即"现在切成了什么样"与"分割器
自己内部意见不一致的地方"。三个值得注意的 flat/负贡献:
主干原始图像置零不降反平（+1.0pp）—— 视觉理解已完全由 SAM2 嵌入分支承载,
原始像素是冗余的; 置零**自信度通道**反而 +1.0pp / ATTC -0.08 —— 与停手护栏
负结果同源（predicted-IoU 噪声大）; 历史正点击图置零无变化（当前 mask 的
形状已隐含点过哪里）。重训式消融是金标准, 但每组 ~40 分钟训练、13 组
超出 CPU 预算, 置零版足以回答"策略在看什么"。

**⑦ 随机医生反常的解释**（ISIC: 随机 97.6% vs 规则医生 90.4%, 不一致对 19:1）。
配对回合分析（`scripts/analyze_doctor_anomaly.py`）把机制钉死:
- 19 个随机独赢的回合里, 规则医生 **19/19 全部 max_clicks 卡死**（9 次点完终
  Dice 仅 0.683）, 随机医生平均 5.1 次解决; 0 例提前误停。
- 规则医生相邻点击间距 **0.86** r_eq（最大误差域质心 + 3px 抖动 → 相邻两笔几乎
  落在同一点, 提示冗余）; 随机医生 **1.24** r_eq —— 每次交互都是新信息。
- 机制验证（`MultiCandidateDoctor`: GT 误差带多样采样 + predicted-IoU 试选）:
  规则医生 90.4% → 多候选 94.4%（+4pp）; 而去掉打分、同样多样采样的对照
  **95.6%** 反而更高 —— 选优不仅无增益还有害（与停手护栏负结果同源:
  predicted-IoU 噪声大）, 仍略低于纯随机 97.6%（2pp 在噪声带内）。
- 结论: **反常 = 提示多样性的价值, "试选打分"是反效果**。
- **但"更强教师 → 蒸馏更强 BC"被实验否决**（全管线对照, 同数据/种子/协议,
  唯一差异是教师; `doctor.teacher: multi_ns | rule`）: 多候选教师蒸馏出
  BC 80.4% / ATTC 3.18, 规则教师蒸馏出 **82.4% / 2.98** —— 规则教师反而
  +2pp（验证集同向: 94.7% vs 92.7%）。解释: 多样教师同一状态可去多个位置,
  **点击标签熵更高, 行为克隆拟合多模态目标更难**; 教师端的"试了再选"优势
  依赖分割器实时反馈, 学生没有这个能力。教师自身的 95.6% 是蒸馏上限的
  必要非充分条件。后续方向: 多候选轨迹作数据增广而非标签替换, 或改用
  "哪个点击更好"的排序/RL 目标替代逐点模仿。

## 方法学要点

- **模仿的状态不含 GT**：策略只能看图像+当前分割+历史点击（推理时医生不在场），
  "哪里切错了"是策略从图像-分割一致性里自己推断的；GT 只用于医生模拟与评测。
- **动作离散化**：点击位置量化为 16×16 网格 × {正, 负} + 确认，共 513 类；
  格内亚像素偏移由偏移头回归（`policy.fine_offset`），把有效点击精度从
  8px 提到约 4px，动作空间本身保持离散。
- **防泄漏**：BC 训练/验证按**图像（回合）**划分；策略训练用的状态全部来自
  决策时刻可得信息。
- **医生噪声建模**：点击抖动 σ=3px、15% 概率次优点击，让策略对不完美示范鲁棒；
  这些参数在 `doctor:` 下可调。
- **框选**：v1 中框选作为分割器的提示接口与医生初始化消融保留
  （`segmenter.add_box`），策略动作空间暂只含 点击/擦除/确认；策略加 box 头是
  直接扩展。
- **替身 ≠ MedSAM2**：U-Net 替身用于 CPU 验证整套模仿学习闭环；论文结果必须
  用真 MedSAM2 后端 + 真实数据复跑。
